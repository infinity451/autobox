# static/ 前端页面说明

这是 AutoBox 的前端（用户看到的界面），用 HTML + CSS + JavaScript 编写。
浏览器打开 http://127.0.0.1:8000 时，展示的就是这里的文件。

## 三种文件的分工（网页的三层结构）

| 类型 | 后缀 | 负责什么 | 类比 |
|---|---|---|---|
| HTML | `.html` | 页面的「骨架」：有哪些标题、按钮、输入框 | 房子的毛坯结构 |
| CSS | `.css` | 页面的「装修」：颜色、大小、圆角、间距 | 房子的装修 |
| JavaScript | `.js` | 页面的「大脑」：点击按钮后做什么、怎么请求数据 | 房子里的人 |

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 首页·功能中心：展示 5 个功能模块卡片（规则管家/采集器/批量魔法/定时中心可进入，宏录制器开发中） |
| `rules.html` | 规则管家页面：规则列表 + 新建/编辑表单 + 运行日志 |
| `crawler.html` | 网页采集器页面：采集任务列表 + 新建任务表单 + 运行结果预览 + 采集历史 |
| `batch.html` | 批量文件魔法页面：批量重命名（预览→确认→执行） |
| `timer.html` | 定时提醒中心页面：定时提醒/关机/重启/休眠/打开程序 |
| `test_page.html` | 本地模拟新闻站：采集器练手用的测试网页（不依赖外网） |
| `css/style.css` | 全局样式：所有页面共用的颜色、按钮、卡片、表单样式 |
| `js/api.js` | API 工具库：封装「请求后端接口」的函数（规则/采集器/批量/定时四套） |
| `js/index.js` | 首页脚本：把引擎状态显示到首页顶部 |
| `js/rules.js` | 规则管家脚本 |
| `js/crawler.js` | 采集器脚本 |
| `js/batch.js` | 批量文件魔法脚本 |
| `js/timer.js` | 定时提醒中心脚本 |

## 目录说明

- `css/`：存放所有样式表（目前就一个 style.css）
- `js/`：存放所有脚本（api.js / index.js / rules.js / crawler.js / batch.js / timer.js）

## 前后端怎么通信

网页里用浏览器自带的 fetch 发 HTTP 请求，调用后端 `app/api.py` 的接口：
- 网页加载 → `js/api.js` 调 `GET /api/rules` → 后端返回规则列表 → 网页渲染显示
- 点保存 → 调 `POST /api/rules` → 后端存数据库并刷新引擎 → 网页刷新列表
