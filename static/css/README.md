# static/css/ 样式文件说明

存放网页的「装修」文件——控制颜色、大小、圆角、间距等外观。

## 文件清单

| 文件 | 作用 |
|---|---|
| `style.css` | 全局样式表，所有页面共用。定义了：顶部导航栏、卡片、按钮（主/次/危险）、表单输入框、规则列表、日志颜色等 |

## 常用样式速查（改外观时用）

| 类名 | 效果 |
|---|---|
| `.card` | 白色圆角卡片（页面上常见的白色方块） |
| `.btn-primary` | 蓝色主按钮 |
| `.btn-ghost` | 浅蓝次按钮 |
| `.btn-danger` | 红色危险按钮（删除类操作） |
| `.muted` | 灰色说明文字 |
| `.log-success` / `.log-error` / `.log-info` | 日志颜色：绿 / 红 / 蓝 |

想改主题色：搜 `#4f6ef7`（主蓝色），全局替换成你喜欢的颜色即可。
