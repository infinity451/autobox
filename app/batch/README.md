# app/batch/ 批量文件魔法包说明

批量文件魔法（第 3 阶段）：批量重命名工具——先预览（旧名→新名对照表），确认后执行。

## 文件清单

| 文件 | 作用 |
|---|---|
| `__init__.py` | 包的身份证 |
| `rename.py` | 批量重命名引擎：`preview_rename` 预览 + `execute_rename` 执行 |

## 四种重命名模式

| 模式 | 效果 | 参数 |
|---|---|---|
| `prefix` 加前缀 | `报告.txt` → `工作_报告.txt` | prefix="工作_" |
| `suffix` 加后缀 | `报告.txt` → `报告_终版.txt` | suffix="_终版" |
| `replace` 替换 | `报告副本.txt` → `报告.txt` | find="副本", replace="" |
| `sequence` 加序号 | `报告.txt` → `001_报告.txt` | position=prefix/suffix |

## 安全设计（重点）

1. **先预览后执行**：执行前必须先算出对照表给用户看
2. **冲突检测**：两个文件改成同名、或新名已存在时标记冲突，执行时跳过（绝不覆盖）
3. **跳过无变化**：新名等于旧名的项不执行
4. **单个失败不连坐**：某个文件改名失败（被占用等）只记录错误，不影响其他文件

## 局限

- 只处理指定文件夹的**一层文件**（不递归子文件夹，安全考虑）
- 一次最多处理 200 个文件（防止误操作范围过大）
- 没有"撤销"功能（v2 优化项），执行前请确认
