# app/macro/ 宏录制器包说明

宏录制器（第 4 阶段）：录制鼠标键盘操作 → 保存为宏 → 一键回放。
把重复操作自动化，例如：每天"打开记事本 → 输入固定文字 → 保存"录一次就能回放。

## 文件清单

| 文件 | 作用 |
|---|---|
| `__init__.py` | 包的身份证 |
| `store.py` | 宏存储：增删改查（存数据库 macros 表） |
| `recorder.py` | 录制器：pynput 监听鼠标键盘 → 事件序列（含操作间隔 delay） |
| `player.py` | 回放器：pynput 重放事件（速度控制 + F8 紧急停止） |

## 事件格式（一条条操作记录）

```json
{"type": "move",   "x": 100, "y": 200, "delay": 0.05}                       鼠标移动
{"type": "click",  "button": "left", "pressed": true, "x": 100, "y": 200}    点击
{"type": "scroll", "dx": 0, "dy": -1}                                        滚轮
{"type": "key",    "key": "a", "pressed": true}                              按键
```

`delay` = 这条事件距录制开始的时间（秒），回放时用它还原"操作节奏"。

## 工作原理

- **录制**：pynput 的 Listener 在后台监听，用户一动鼠标键盘就记录事件（recorder.py）
- **回放**：pynput 的 Controller 假装用户操作——移动鼠标、点击、按键（player.py）
- **速度**：事件间隔除以速度倍率（2x = 一半等待时间）
- **紧急停止**：回放中按 F8 立即停止（监听器一直在后台）

## 安全设计（重要，读 player.py）

1. **回放会真的操作电脑**：前端播放前有强确认弹窗
2. **紧急停止键 F8**：失控时随时中断
3. **速度下限保护**：speed 最小 0.5，防止 0/负数导致卡死
4. **单实例回放**：回放中不允许再触发回放（防重入）

## 局限

- 回放依赖"屏幕状态跟录制时一样"（窗口位置、界面布局变了会点错地方）——这是所有宏工具的通病
- 键盘监听在某些特殊环境可能需要管理员权限（pynput 全局钩子）
- 没有自动校准（图像识别找位置），v2 优化项
