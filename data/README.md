# data/ 数据目录说明

存放 AutoBox 运行时产生的数据文件。**这个目录的内容是程序自动生成的，不要手动删改里面的数据库文件**（删了规则就没了）。

## 文件清单

| 文件/目录 | 作用 |
|---|---|
| `autobox.db` | 主数据库（SQLite 格式）：所有规则、运行日志、设置都存在这里。程序第一次启动时自动创建 |
| `test_download/` | 测试用的「模拟下载目录」：往里面丢文件，测试规则管家的自动归档效果 |
| `test_moved/` | 测试用的「模拟目标目录」：被自动归档的文件会出现在这里 |

## 为什么数据要存在本地

- 你的规则、日志都是**私人的东西**，存在本机比上传云端更安全
- 想备份/迁移：直接复制 `autobox.db` 文件到另一台电脑即可

## 测试目录说明

`test_download` 和 `test_moved` 是演示「规则管家」用的虚拟目录：
网页上建一条规则（监控 test_download，移动 txt 文件到 test_moved），
然后往 test_download 丢一个 .txt 文件，几秒后它就会出现在 test_moved 里。

实际使用时应把监控目录改成你自己的目录，比如 `C:/Users/你的名字/Downloads`。
